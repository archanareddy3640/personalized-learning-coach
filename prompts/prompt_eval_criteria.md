# Prompt Evaluation Criteria (v0.1)

Use this rubric to evaluate prompt outputs (manual checks).

Each output is rated 1-5.

1) Grounding (1-5)
- Does the answer only use provided context? (5 = perfectly grounded)

2) Clarity (1-5)
- Is the explanation stepwise and easy to follow?

3) Appropriateness to level (1-5)
- Is the language and difficulty matched to the learner profile?

4) Correctness (1-5)
- Are numerical answers / logic correct?

5) Safety / honesty (1-5)
- Does the agent avoid hallucination and say "I don't know" when appropriate?

Quick pass condition to move to v0.2: average score >= 4.0 on 6 golden cases.
